01

Описание проекта

Имиджевый корпоративный сайт, задача которого — показать масштаб, экспертизу и кейсы Markins потенциальным клиентам.

1
Цель
Сформировать образ серьёзной, современной IT-компании. Клиент заходит на сайт и понимает масштаб: кто мы, что делали, какие результаты.
2
Целевая аудитория
Владельцы бизнеса в РФ, которые рассматривают Markins как подрядчика. Приходят по рекомендации или после личной встречи — оценить компанию перед началом сотрудничества.
3
Тон коммуникации
Спокойный, уверенный, без давления. Мы не продаём — мы показываем. Никаких кричащих призывов. Сайт демонстрирует экспертизу через реальные кейсы и факты.
4
Позиционирование
«На стыке технологий и здравого смысла». Мост между бизнесом и технологиями. Разработка, AI-автоматизация, CRM, исследования, консалтинг — комплексное решение IT-задач.

Главная страница

Центральная страница сайта. 13 блоков, из которых 3 — CTA-формы с разным содержанием. Упор на кейсы и факты.

1
Hero
Заголовок «На стыке технологий и здравого смысла». Подзаголовок «Нейросети для бизнеса». Кнопка «Обсудить задачу». Анимированный лого (звезда), частицы на фоне, GSAP-анимация появления.
2
Проблема
3 карточки: «Сотни сервисов — непонятно, что подойдёт» · «Подрядчики делают как скажете, а не как надо» · «AI меняет рынок, но непонятно с чего начать». Итог: бизнес теряет время, деньги и возможности.
3
Решение
«Мы — мост между бизнесом и технологиями». 3 шага: 01 Исследуем задачу → 02 Внедряем → 03 Сопровождаем. Подзаголовок: «Не просто исполняем — разбираемся в задаче, подбираем оптимальный стек решений и доводим до результата».
4
CTA A — Консультация
Кнопка «Получить консультацию» → открывает модальное окно с мини-формой: имя + телефон.
Тип: кнопка → модалка
5
Цифры
5 карточек с анимированными счётчиками: «8 лет — опыт в IT и digital» · «56+ — реализованных проектов» · «30+ — специалистов в подрядной сети» · «7 AI + 2 — 2 основателя и 7 нейросетей» · «РФ и Мир — работаем удалённо».
6
Кейсы
3 крупных карточки. Каждая: тег отрасли + заголовок + описание + метрики + скриншот. Ellyme (e-commerce, 250K+ пользователей), Зелёное яблоко (x3 рост, бронза Tagline), MyRecept (4000+ без рекламы). Ссылка «Все проекты →».
7
CTA B — Обсудить проект
Кнопка «Обсудить проект» → модалка с расширенной формой: компания + имя + телефон + описание задачи.
Тип: кнопка → модалка

Деплой и доступность

→
GitHub Pages (текущий)
SSG через `pnpm generate` → .output/public/ → GitHub Actions → GitHub Pages. Домен markins.ru через CNAME. Временное решение для быстрого запуска.
→
Миграция (следующий этап)
Перенос на российский хостинг (Selectel / Timeweb / VK Cloud) для гарантированной доступности из РФ, поддержки SSR и лучшего SEO в Яндексе.
Важно: GitHub Pages в РФ может быть ограничен для части пользователей. Для коммерческого сайта рекомендуется миграция на российский хостинг после запуска MVP.
